# نسخة الهاتف المحلية التشغيلية

ملف واحد يعمل دون خادم أو ملفات خارجية. هذه نسخة عمليات محلية مستقلة مبنية على نواة المبيعات، وليست طبقة تشغيل Python داخل المتصفح، ولا تزامن بياناتها تلقائياً مع نسخة الخادم.

## على الهاتف

1. نزّل ZIP وفك الضغط من تطبيق «ملفاتي».
2. افتح `WIFI-HOME-OFFLINE.html` بمتصفح يدعم JavaScript مثل Chrome. لا تفتحه كملف نصي أو داخل معاينة GitHub.
3. افتح «الإعدادات والبيانات» واختر ملف JSON الذي صدّرته من النظام القديم.
4. راجع ملخص الاستيراد واضغط موافق. تُستبعد بيانات التجربة المعلّمة وهويات V47 المعروفة، ويُرفض حذف تجربة مرتبطة بمعاملة فعلية لاحقة.
5. بعد العمل اضغط «حفظ نسخة الهاتف» وتأكد من تنزيل ملف HTML الجديد. يحتوي الملف بياناتك؛ افتحه في المرة التالية واحتفظ به بشكل خاص. نسخة JSON متاحة أيضاً للاستعادة.

البرنامج الذي ينزل من GitHub فارغ ولا يحتوي بيانات العميل الخاصة. ملف النسخة الاحتياطية المرفق في المحادثة لا يُنشر مع البرنامج. يُستورد الملف الموجود أصلاً على هاتفك. إذا كان المخزون الأساسي صفراً، يلزم استلام مخزون قبل بيع أصناف مخزنية؛ لا تُضاف كميات تجريبية.

## العمليات

بيع نقدي وآجل وسداد جزئي، خصم إجمالي، تعديل الفاتورة بسبب موثق مع عكس الآثار السابقة ومراجعة محفوظة، إلغاء محاسبي، قبض ومصروفات، تمويل صندوق مستقل عن الإيراد، استلام مخزون، إضافة وتعديل بيانات العملاء وأسعار الأصناف، حدود ائتمان، تقارير حسب الفترة والعميل والصنف، كشف حساب، تصدير CSV، ومستند فاتورة/تقرير مستقل للطباعة أو حفظ HTML. حفظ PDF يعتمد على دعم متصفح الهاتف للطباعة، وليس توليد PDF من خادم.

لا تتضمن هذه النسخة المحلية وظائف نسخة الخادم الخاصة بالبنوك والتسويات والمستودعات المتعددة وأوامر الشراء ومرتجعاتها أو صلاحيات عدة مستخدمين. لا يوجد تسجيل دخول يفرض حماية على الملف المحلي. لا تعتبر هذه النسخة مطابقة لكل ميزات الخادم أو نظام ERP مكتمل.

## بقاء البيانات

عند إتاحة `localStorage` تحفظ العمليات فيه، مع رفض الكتابة فوق تعديل تبويب آخر. بعض موفري ملفات أندرويد يمنعون التخزين الدائم؛ يظهر تنبيه دائم عند ذلك وتعمل العمليات في الذاكرة. في هذه الحالة يجب حفظ ملف الهاتف الجديد أو JSON قبل الإغلاق. مجرد فتح ملف قديم لن يعيد العمليات التي لم تصدّرها. زر الحفظ يطلب التنزيل من المتصفح؛ تأكد فعلياً من ظهور الملف في التنزيلات. لا تمسح بيانات المتصفح دون نسخة خارجية.

ملف الهاتف المحفوظ يضم قاعدة البيانات داخل JSON آمن في HTML. عند فتحه يستعيد البيانات بهوية تخزين جديدة حتى لا تستبدلها نسخة أقدم من التخزين. الملف خاص بمن يحوزه؛ لا ترفعه لمستودع عام ولا تشاركه كبرنامج فارغ. يظل البرنامج العام قابلاً للمشاركة دون بيانات.

## الاختبار

`node --test tests/erp.test.mjs tests/offline.test.mjs`: الحسابات والتعديل والعكس والائتمان والمخزون والفلترة واستبعاد التجربة والتحقق من القيود.

`python scripts/check_offline_browser.py`: يتطلب Playwright وChromium في بيئة الاختبار فقط. يفحص البيع والتعديل والقبض والرصيد ونسخ JSON وHTML وإعادة الفتح والمستند المستقل، مرة مع التخزين ومرة مع منع التخزين. لا يحتاج Playwright في الهاتف. قيود بيئة الاختبار تمنع `file://`؛ استخدمت خدمة محلية للاختبار فقط، والملف الموزع لا يطلب شبكة. لم تُجر التجربة على هاتف أندرويد فعلي؛ التنفيذ والتنزيل يعتمدان على موفر الملفات والمتصفح.

للبناء: `python scripts/build_offline.py offline/dist/WIFI-HOME-OFFLINE.html`. لا تمرّر بيانات خاصة إلى المجلد الموزع ولا تضع قاعدة بيانات العميل فيه.
