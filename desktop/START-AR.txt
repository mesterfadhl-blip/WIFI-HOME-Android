واي فاي هوم — تشغيل الكمبيوتر على Windows 10/11، إصدار 64 بت

هذه نفس واجهة النظام الجديد وكوده، مع محرك Python رسمي مرفق وقاعدة بياناتك الأساسية.
لا تحتاج استضافة أو إنترنت بعد التنزيل، ولا تثبيت Python أو رفع ملفات لموقع.

الفتح:
1. فك ضغط ZIP بالكامل بواسطة «استخراج الكل». لا تشغل الملفات من داخل نافذة الملف المضغوط.
2. أغلق أي نافذة تشغيل قديمة للنظام، ثم افتح START-WIFI-HOME.bat بنقرتين.
3. سيُفتح النظام في متصفح الكمبيوتر الافتراضي. اترك نافذة التشغيل مفتوحة أثناء العمل.
4. عند أول تشغيل أنشئ المدير وكلمة المرور. إذا كان لديك حساب مدير سابق في تثبيت الكمبيوتر الفارغ، يبقى كما هو؛ لا تُغيّر كلمة مروره تلقائياً.
5. لإيقاف النظام أغلق نافذة التشغيل أو اضغط Ctrl+C فيها. البيانات محفوظة على القرص.

البيانات المرفقة:
18 عميلاً أساسياً، و10 أصناف، والفاتورة الأساسية، ورصيد صندوق 9,000 ريال، دون بيانات التجربة.
المخزون الأساسي صفر؛ استلم كمية فعلية قبل بيع صنف مخزني.
seed\DATABASE.sqlite3 هي نسخة البداية الخاصة بك وليست ملف العمل اليومي.

الحفظ والتحديث:
تُحفظ قاعدة العمل تلقائياً في:
%LOCALAPPDATA%\WIFI-HOME-ERP\data.sqlite3
وهذا المسار خارج مجلد البرنامج، لذا إعادة فك ضغط تحديث لا تمسح عملياتك.
إذا وُجدت بيانات عمل سابقة يستخدمها النظام ولا يستبدلها بقاعدة البداية.
إذا كان التثبيت السابق فارغاً تماماً من البيانات المالية يضيف بيانات البداية بمعاملة واحدة، مع الإبقاء على حسابات الدخول وسجل العمليات.
يأخذ نسخة احتياطية متسقة قبل كل تشغيل لقاعدة موجودة، داخل مجلد backups بجانب قاعدة العمل. لا يحذف النسخ القديمة تلقائياً.
فتح START مرة ثانية يفتح نفس جلسة الخادم الجاري؛ لا ينشئ قاعدة أو نسخة تشغيل أخرى.

النسخ الاحتياطي:
شغل BACKUP-DATA.bat لإنشاء نسخة متسقة في MY-BACKUPS بجانب ملفات البرنامج.
يمكن تشغيل النسخ الاحتياطي أثناء عمل النظام. احتفظ بنسخ خاصة خارج الكمبيوتر أيضاً.
لا تنسخ ملف قاعدة يعمل يدوياً دون الأداة، لأن بعض التغييرات قد تكون في WAL.

إذا تعذر الفتح:
تأكد من استخراج المجلد كله ووجود runtime\python.exe، وأن Windows لديك 64 بت.
احتفظ برسالة الخطأ ولا تحذف بيانات النظام. التفاصيل تُكتب في:
%LOCALAPPDATA%\WIFI-HOME-ERP\last-start-error.txt
التشغيل محلي على الكمبيوتر نفسه؛ لا يحتاج فتح منافذ إنترنت أو تعطيل مضاد الفيروسات.

الخصوصية والحدود:
الحزمة تحتوي بيانات عملائك؛ لا ترفعها إلى GitHub ولا تشاركها كبرنامج عام.
أقسام النظام المبنية حالياً محفوظة، وهذه ليست شهادة اكتمال لكل ميزات ERP التجارية.
لا يوجد نشر عام أو مزامنة مع الهاتف في هذه الحزمة. النسخ الاحتياطي الخارجي السحابي غير مفعّل.
المحرك المرفق هو Python Software Foundation من NuGet الرسمي، وقد تحققت بصمة SHA512 وملفات التشغيل. تراخيصه داخل runtime\LICENSE.txt.
اختُبر الخادم والواجهة وحفظ البيانات وإعادة التشغيل في بيئة التطوير. لا تتوفر هنا آلة Windows فعلية لاختبار ملف exe عليها.
